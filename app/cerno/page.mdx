# Cerno

[Cerno](https://cernosearch.com) is AI search for e-commerce. It replaces the default search bar with one that handles both kinds of shoppers: the one who types `wool runner mizzle navy 42` and the one who types "a gift for my dad who runs in the rain".

Most store search only handles the first kind. Semantic search handles the second but makes the first slower and fuzzier. Cerno routes each query to the right engine.

### What Makes It Different

- **Exact queries never touch the model.** SKUs, product names, and sizes hit a keyword index and return in milliseconds.
- **Vague queries get understood.** "Something that smells like chocolate" or "linen shirt under 50 dollars" go through embeddings and return the products that match the intent.
- **No synonym lists to maintain.** Misspellings, plurals, and regional spellings resolve without setup. "Moisturiser for sensitiv skin" works.
- **Merchandising stays yours.** Boost, hide, and pin rules sit on top of the AI ranking.
- **Analytics that point at gaps.** See zero-result queries and click-through, so you know what customers want and don't find.

It ships as a Shopify app, a headless API, and a typed SDK (`@ribban/cerno`). The catalog syncs within minutes, and a Shopify store can go live the same day.
