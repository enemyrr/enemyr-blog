# Quarry

[Quarry](https://ribban.co/lab/quarry) is a fast, native macOS workspace for your databases, built by [RIBBAN](/ribban). Connect PostgreSQL, MySQL, MariaDB, MongoDB, SQLite, or Convex and work with the data in one app. No Electron, no browser tabs.

Most database clients are either native and dated, or modern and slow. Quarry is written in Swift with AppKit and SwiftUI, so it starts instantly and behaves like a Mac app should.

### What Makes It Different

- **Six databases, one model.** Relational, document, and Convex connections share the same workspace, grid, and query tools.
- **A grid you can edit.** Browse, filter, sort, copy, paste, and edit rows in place.
- **Notebooks and dashboards.** Combine queries, values, text, and charts on a canvas, then publish the result as a native dashboard.
- **An assistant with context.** It already knows the database, schema, and rows you're looking at. Generated writes wait for your review before they run.
- **Real-world connections.** SSH tunnels, SSL certificates, URI import, local SQLite files, and automatic discovery of Docker databases.
- **Secure by default.** Secrets live in the Keychain and query history is encrypted.

Quarry started as a fork of [Pluk](https://github.com/pluk-inc/Pluk). It's open source under AGPL-3.0 and runs on macOS 15 or later.
